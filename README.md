# Gartenbewässerung

Bewässerungsassistent für den Garten: sagt, ob und wie viel heute gegossen werden soll – weder zu viel noch zu wenig.

- **App öffnen:** https://paci1-fun.github.io/gartenbewaesserung/
- Die App besteht aus einer einzigen Datei (`index.html`) und dem Erklärvideo (`erklaervideo.mp4`).
- Angaben werden nur im Browser des jeweiligen Geräts gespeichert.
- Wetterdaten: [Open-Meteo.com](https://open-meteo.com/) (Lizenz CC BY 4.0, kostenlos für nicht-kommerzielle Nutzung).

Die Empfehlungen sind Richtwerte, keine Messungen. Prototyp.
